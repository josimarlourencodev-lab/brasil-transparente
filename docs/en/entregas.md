# Deliveries by Area

Detailed record of what has been built so far, area by area.

## Web (Next.js)

- Public pages for **news**, **politicians** and each one's **detail**, with light/dark mode and search.
- **Podcast page** (`/podcast`) listing episodes with thumbnail, duration, date and an `<audio>` player.
- **Public API** (`/api/noticias`, `/api/politicos`, `/api/podcast/episodios`) serving data with public RLS.
- **`/admin` panel** — login with `ADMIN_PASSWORD` (HttpOnly cookie, constant-time comparison), status-based viewing and **manual add/remove of articles** (upsert by `url` and `DELETE` by `id`).
- **`/pitch` page** — project presentation: 10 slides (1920×1080, `#0F4C81`/`#C8102E` palette), AI voice narration (`edge-tts`, PT-BR), per-slide audio player, a ready **MP4 video** with player/download, and script download.
- **`/documentacao` page** — internal documentation within the same Design System (about, autonomous operation, methodology, principles/code of conduct and access), without leaving the portal.
- **Navigation** — "GitHub" (new tab) and "Documentation" in the header; "O Brasil Transparente" (pitch), "Documentation" and "GitHub repository" in the footer.
- **PWA** — manifest and service worker (basic offline).
- **Massive SEO** — news/politician/list/podcast page content rendered on the
  server (SSR, no "Loading…"); `generateMetadata` per page (title, description,
  OG, Twitter, canonical); `sitemap.xml` (static + news/politicians); `robots.txt`;
  `rss.xml` feed; default OG image (`/opengraph-image`, 1200×630); JSON-LD
  (Organization/WebSite on home, NewsArticle + BreadcrumbList on news, Person +
  BreadcrumbList on politicians, ItemList on lists, PodcastSeries on podcast).
- **Fixes over time:** dark mode, responsive layout, removal of the "Auditor's panel" link from the footer.

## Mobile (Expo / React Native — `apps/mobile`)

- News and politicians list and detail with **photos**, **dark mode** and icon/branding.
- **Background podcast player:**
  - Global reusable player in `src/lib/audio.ts`.
  - `setAudioModeAsync({ playsInSilentMode, shouldPlayInBackground, interruptionMode })`.
  - `setActiveForLockScreen(true, { title, artist, artworkUrl }, { showSeekBackward, showSeekForward })`.
  - `expo-audio` plugin with `enableBackgroundPlayback` in `app.json`.
  - Android manifest with `AudioControlsService` + `FOREGROUND_SERVICE_MEDIA_PLAYBACK`.
  - Notification permission requested on Android 13+.
- **Episode thumbnails** shown in the card (via `expo-image`) and used as **lock screen artwork**.

## Ingestion (Python)

- **Crawlers:** generic RSS/Atom + politician-targeted collection (Google News RSS by term).
- **Pipeline:** feed → crawler → dedupe → sanitize (anti-XSS) → source type → LLM synthesis → upsert.
- **`worker.py`:** APScheduler scheduler (interval configurable by env).
- **Topic restriction:** the synthesis prompt marks celebrities/famous people/sports/soccer/entertainment/soap operas/shows as `relevante: false`; items outside the topic are **not published**.

## AI synthesis

- LLM (Groq/Together/Gemini) generates structured JSON: `resumo`, `categoria`, `envolvidos`, `contradicao`.
- **Neutrality:** explicit prohibition of value-laden adjectives, opinion or moral judgment.
- **Contradictions:** compares with the history of past statements and points out factual contradictions with references.

## Weekly podcast

- **Script** generated by a dedicated LLM model (separate from the daily synthesis model).
- **Narration** in PT-BR via `edge-tts` (free, Microsoft Edge network).
- **Upload** of the MP3 + thumbnail to the public `podcast` bucket on Supabase Storage.
- **Record** in `podcast_episodios` with `titulo`, `roteiro`, `audio_url`, `thumb_url`, duration and date.
- **Automatic thumbnail generation** (Pillow, JPEG 1200×675, site palette `#0F4C81`/`#C8102E`).

## Database (Supabase)

- Tables: `politicos`, `noticias`, `fontes`, `categorias`, `historico`, `audit_log` and `podcast_episodios`.
- RLS enabled: public read only for `status='publicado'`; writes only via `service_role`.
- `pg_trgm` extension enabled (advanced search in the future).

## CI/CD

- **`ci.yml`** — OSV audit, pytest, Vitest, lint, typecheck, build (push/PR).
- **`ingest.yml`** — scheduled ingestion with repository secrets.
- **`podcast.yml`** — weekly podcast generation with audited-dependency checks.
